1️⃣ ¿QUÉ NECESITAS?
Elemento	Descripción
Archivo PGN original	El que exportas desde ChessBase, SCID, o cualquier programa de ajedrez
pgn-extract.exe	Programa que limpia los PGN (elimina comentarios, números, etc.)
pgn-extract-autoclean.bat	Script que facilita el uso de pgn-extract
convertidor.html	El archivo HTML que te proporcioné para convertir a formato JSON
Bloc de notas	Para copiar y pegar el contenido

3️⃣ PASO 1: OBTENER EL ARCHIVO PGN ORIGINAL
Desde ChessBase:
1.	Abre tu base de datos
2.	Selecciona las partidas que quieras exportar
3.	Menú: Archivo → Exportar → Partidas como PGN
4.	Guarda el archivo en la carpeta convertidor-pgn
Desde SCID:
1.	Abre tu base de datos
2.	Selecciona las partidas
3.	Menú: File → Export → Games as PGN
4.	Guarda en la carpeta
Desde Lichess/Chess.com:
1.	Abre la partida
2.	Busca el botón "PGN" o "Descargar PGN"
3.	Copia el texto y pégalo en el Bloc de notas
4.	Guarda como mis_problemas.pgn en la carpeta
Importante: El archivo puede tener muchos problemas juntos, uno tras otro. Eso está bien.
________________________________________
4️⃣ PASO 2: LIMPIAR EL PGN CON pgn-extract
¿Por qué limpiar?
Los PGN de ChessBase/SCID vienen con:
•	Comentarios { ... }
•	Números de movimientos 1., 2.
•	Variantes ( ... )
•	Información extra que no necesitamos
Ejecutar el limpiador:
1.	Abre una terminal en la carpeta convertidor-pgn:
text
cd D:\Users\Oscar\Downloads\Ajedrez\-\PROYECTOS\convertidor-pgn
2.	Ejecuta el script:

3.	Verás esta pantalla:

========================================

3.	Selecciona "Abrir con" → Bloc de notas

8️⃣ SOLUCIÓN DE PROBLEMAS COMUNES
❌ "pgn-extract.exe no encontrado"
Solución: Descarga el programa de:
https://www.cs.kent.ac.uk/people/staff/djb/pgn-extract/
Coloca pgn-extract.exe en la misma carpeta que el script .bat
❌ "No hay archivos .pgn"
Solución: Asegúrate de tener archivos con extensión .pgn en la carpeta
❌ El convertidor HTML no muestra resultados
Solución:
•	Asegúrate de que el PGN tenga el formato correcto
•	Debe tener al menos un [FEN "..."] y una línea con movimientos
❌ Los movimientos salen mal en el servidor
Solución:
•	Revisa que no haya números en los movimientos (1.e4, 2.Nf3)
•	El limpiador debería haberlos quitado, si no, ejecuta el .bat de nuevo
❌ Quiero cambiar el objetivo de los problemas
Solución: En el convertidor HTML, modifica esta línea:
javascript
objetivo = "Ejercicio mixto";
Cámbiala por lo que quieras, por ejemplo:
javascript
objetivo = "Mate en 2";
